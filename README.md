# Newton Divided Difference Interpolation

A simple web application that demonstrates the **Newton Divided Difference Interpolation** method. Users can enter data points and calculate interpolated values through an interactive interface.

## Features

* Input custom data points
* Calculate interpolated values
* Simple and responsive interface
* Python implementation included

## Technologies Used

* HTML
* CSS
* JavaScript
* Python

```text
.

```

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/newton-divided-difference.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.
